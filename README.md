# Bomb Arena: Nova Era

Jogo independente de ação e labirinto com bombas, inspirado na fórmula clássica dos jogos de arena. Não usa ROM, sprites, músicas ou código do jogo original.

## Primeira versão jogável
- Campanha com fases geradas e inimigos.
- Modo batalha local para dois jogadores.
- Controles de toque para Android e teclado para testes.
- Explosões, blocos destrutíveis e cenário em grade.
- Aplicativo Android em tela cheia (WebView).

## Compilar APK
O GitHub Actions compila automaticamente a cada push na branch main. Abra Actions e baixe o Artifact `bomb-arena-nova-era-debug`.

## Controles
Jogador 1: direcional na tela + botão BOMBA (ou setas + Espaço).
Jogador 2: direcional da direita (ou WASD + Shift).

## Próximas expansões
Cooperação real de campanha, chefes, power-ups, mapas desenhados à mão, áudio original e multiplayer online serão adicionados em etapas. O modo batalha atual é local no mesmo dispositivo.

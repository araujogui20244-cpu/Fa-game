# Super Bomberman 5 PLUS

Esta pasta contém apenas as alterações próprias do PLUS, separadas da base original.

## Etapas
1. Integrar o submenu MULTIPLAYER no menu de título.
2. NORMAL GAME: iniciar a campanha cooperativa para dois jogadores.
3. BATTLE: configurar até quatro participantes, respeitando os limites reais do netplay.
4. Criar a continuação da campanha após o final original.
5. Adicionar músicas originais ou licenciadas.

Nenhuma dessas alterações de gameplay está implementada ainda. Só marcar como concluída depois de compilar e testar.
